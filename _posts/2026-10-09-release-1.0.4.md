This version is backwards compatible with save states from SameBoy 0.14.3 and newer, as well as save states from any BESS compliant emulator

### New/Improved Features
* The libretro core now supports API extensions to retrieve additional metadata and create more portable battery save files
* The iOS frontend has been updated with improved iOS 27 support
* iPhone Duo support was added to the iOS frontend
* The CRT scaling filter has been updated with an improved look
* A new Pixelated/Sharp Bilinear scaling filter
    * This new filter is now the default filter in the Cocoa and SDL frontends
* VFS support was added to the libretro core
* Logging support was added to the libretro core
* The libretro core will now render audio directly in the frontend's audio sample rate, if supported
* Recording audio to a VGM log file is now possible in the Cocoa and SDL frontends
* Minor UI improvements in the Cocoa frontend

### Accuracy Improvements/Fixes
* Workboy emulation now correctly reports the current weekday
* Fixed a bug that made certain small ROM files be incorrectly detected as MMM01 cartridges
* More accurate emulation of SGB command processing

### Bug Fixes
* Fixed a bug where periodic battery saves were performed from the wrong thread in the Cocoa frontend, causing debug builds to crash
* Fixed controller hotkeys not working on newer macOS versions in the Cocoa frontend
* Fixed a bug that prevented mapping Load State commands to a controller hotkey in the Cocoa frontend
* The libretro core no longer reports an RTC memory region when emulating cartridges without an RTC
* Fixed a bug that could trigger memory corruptions on x86-64 platforms when loading malformed save states
* Improved sanitization of the Game Boy Printer save state data
* Fixed an incorrectly label “Rumble strength” label in the Cocoa frontend
* File dialogs on Windows now switch Full Screen mode off before they appear, working around bugs in Windows' windowing system
* Fixed a bug that made the Joycon autopair button not work in the Cocoa frontend
* Fixed a bug that made breakpoints created by the `GB_debugger_execute_command` API would not trigger under some conditions when using SameBoy as a library

### Misc Internal Changes
* The build system no longer prints ignored errors when building SameBoy without RGBDS installed if prebuilt boot ROMs are used
* `ibtool` no longer silently fails when building the Cocoa or iOS frontends
* The logging API now has attribute flags that mark if a log line is an error or a warning caused by the previous API call
